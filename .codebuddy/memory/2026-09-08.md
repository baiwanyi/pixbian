- 实现：
  - `FullscreenWindowBase` 增加全屏↔窗口双形态：`ToggleFullscreen()` + `IsFullscreen`；样式位必须对称增删（窗口态恢复 `WS_CAPTION|WS_THICKFRAME` 才能拖动调整），presenter 存字段；窗口态 1280×800 钳制工作区居中 + 取消置顶 + 恢复默认圆角，全屏态反向。`SlideShowWindow` 无需改动（基类能力直用）。
  - 显隐收口：遮罩 / 退出 / 左翻 / 右翻 / 工具栏五个浮动元素全收进 `OverlayLayer` 单容器，动画与 `IsHitTestVisible` 只作用于容器；`HideOverlay` 前查 `OptionsFlyout.IsOpen` 防浮层悬空。
  - 设置写回：放映页注入 `SettingsViewModel`（DI 单例），开关 Toggled → 属性 setter 落盘广播 → MainWindow.ApplySettings → 放映 VM 即时生效；`SlideShowOrder`/`SlideShowSilentPlayback` setter 原本就有。`ApplySettings` 补 `PlayOrder`/`IsSilentPlayback` 的 OnPropertyChanged 驱动图标。
  - 重放：VM 新增 `RestartCommand`（`Stop` → `sequencer.Reset(count,0)` → `Start` → `LoadCurrentAsync`），随机序经 Start 内重洗从首条开始。
  - 图标：播放 E768/E769、顺序 EA37(列表)/E8B1(随机)/E8EE(循环)、声音 E767/E74F、全屏 E740/E73F；点击处理器图标先行切换给即时反馈，广播回流校准。
  - 坑：Flyout 开关程序化赋 `IsOn` 会触发 Toggled → `_isSyncingOptions` 防重入；勿引不存在的 `StaticResource`（XAML 能编译但启动崩）。
