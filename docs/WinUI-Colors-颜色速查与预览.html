WinUI Colors 颜色速查与预览

Pixbian 项目取色基线 · 数据源自 WinUI 3 Microsoft.UI.Colors（反编译自 Windows App SDK 2.1.6），与微软官方文档对齐
关键约束与 XAML / C# 用法

关键约束

  • 所有颜色均为 Microsoft.UI.Colors 的静态属性（WinUI 3 命名空间，非 UWP 的 Windows.UI.Colors），对应 ARGB 值完全一致。
  • 本表共 148 个不透明色 + 1 个透明色（Transparent，Alpha=0x00）。
  • 「十六进制」列为不透明 RGB（#RRGGBB）；若需带透明度，请自行补充 Alpha 通道。
  • 深色主题下预览色块仍显示真实颜色值，便于直接取用，不受页面主题影响。

取色用法（对齐 Pixbian 当前代码风格）

// C# 中（GalleryPage 菜单用红色删除项）
using Microsoft.UI;
var brush = new SolidColorBrush(Microsoft.UI.Colors.Red);

// XAML 中
<SolidColorBrush x:Key="DangerForeground" Color="{ThemeResource SystemColorControlAccentColor}" />
// 或直接引用命名色：
<MenuFlyoutItem Foreground="{ThemeResource SystemControlForegroundBaseHighBrush}" />
