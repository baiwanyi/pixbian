## 删除（Del 键）失效修复
- 现象：选中文件后按 Del 无效，界面无任何反馈
- **根因（存量缺陷，与本轮性能改动无关）**：`DeleteFilesAsync` 中
  `IsDeleteInProgress = true`（467）与复位（原 529）之间是裸流程——回收站 Win32 失败、
  数据库写失败等**任何非 OCE 异常都会跳过复位**；而开头守卫
  `if (items.Count == 0 || IsDeleteInProgress) return (0,0)` 会让此后**所有**删除永久静默失效
- **修复（GalleryViewModel）**：拆出 `RunDeleteLoopAsync`（返回 deleted/failed/cancelled/firstError），
  主方法用 try/catch/finally 包裹——finally 复位 IsDeleteInProgress + 释放 CTS；
  非取消异常收口为「删除中断：异常类型+消息」通知条（不再无反馈）；
  结果文本与统计刷新收口到调用方；索引清理显式 `CancellationToken.None`
  （文件已删，中断会留幽灵条目，CA2016 按语义这样解决）
- **取证埋点（临时）**：`GalleryPage.OnGalleryPageKeyDown` 的 Delete 分支记
  `DELKEY|目标数|是否选择模式|IsDeleteInProgress`——目标数 0=选择/焦点问题，
  第三字段 true=状态机卡死（修复后不应再现）
- 构建 0 警 0 错待实测

## 空状态文案改动导致应用无法启动（已修）
- 用户在 GalleryPage.xaml 空状态区块填错两处：
  1. `Foreground="{ThemeResource TitleTextBlockStyle}"` —— TitleTextBlockStyle 是 **Style**，
     Foreground 需要 **Brush**（类型错误）
  2. `Style="{StaticResource TitleTextBlockFontSize}"` / `BodyTextBlockFontSize`
     ——**这两个资源项目中不存在**，StaticResource 解析失败 → 应用启动即崩
- 修正：Foreground 用画刷（标题 `SystemControlForegroundBaseMediumBrush`、
  说明文字 `TextFillColorSecondaryBrush`），Style 用已定义文本样式
  （`SubtitleTextBlockStyle` / `BodyTextBlockStyle`）；说明文字加 MaxWidth + Wrap + 居中
- 教训：改 XAML 资源引用前先确认资源存在且**类型匹配**（Brush/Style/ double 各有其位）

## 内容区「大小/尺寸/日期」取数链路查证（只读排查，无代码改动）
- 结论：三项**全部来自索引库**，不实时读文件系统
  - 大小 = `MediaItem.FileSize`（库 `file_size`，扫描时 `FileInfo.Length` 写入）
  - 日期 = 库 `taken_utc`，缺失回退 `created_utc`/`modified_utc`（分组标题与右键菜单同源）
  - 尺寸 = 库 `width/height`；仅当库中为 NULL 时才经 `PrefetchDimensionsAsync` 读文件头探测
    （`NeedsDimensionProbe`），`MediaMetadataBackfillService` 回填后该集合为空 → 零文件 IO
- **反直觉发现 1**：库里 `taken_utc` 的唯一写入处是 `MediaIndexingService`，取文件系统时间
  （created 与 modified 较早者），**不是 EXIF 拍摄时间**；回填只写 width/height/duration_ms。
  EXIF 的 `ImageMetadata.TakenAt` 已解析但**未在界面任何位置展示**，也未回写库
- **反直觉发现 2**：展示侧虽不读文件，但**渲染侧有实时文件访问**——`ThumbnailDiskCache`
  命中校验 `IsSourceUnchanged` 会对源媒体文件做一次 `FileInfo` stat（mtime+size 比对条目头），
  每条未命中内存缓存的缩略图都会发生；HDD 上一页 200 条不可忽略。库里已有
  `file_size`/`modified_utc`，理论上可替代（权衡：库值在文件被外部修改后会过期）
- 已知例外（唯一实时读文件的信息展示面）：查看器 EXIF 面板（`ImageMetadataReader` +
  系统属性 `System.Image.Dimensions`）
