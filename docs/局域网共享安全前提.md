# 局域网共享安全前提

> 适用版本：2026-09 及以后。本文界定 Pixbian「局域网访问」功能的威胁模型、内置防护边界与使用前提。
> 与 `docs/审计与对标报告-2026-09-10.md` 的 S-01（明文 HTTP）、S-02（监听范围）两项发现配套阅读。

## 一句话结论

**本功能为「可信私有网络」设计，不适用于不可信网络。** 服务在传输层为**明文 HTTP（无 TLS）**，
仅提供应用层防护；跨网络或不完全可信环境请经反向代理终止 TLS，或改用具 RBAC 与审计体系的服务。

## 威胁模型

| 项 | 说明 |
|---|---|
| 保护对象 | 索引中的媒体文件（含元数据、缩略图、原图与视频）与共享会话 |
| 假定可信 | 同网段的设备与网络链路（家庭 / 自建「专用」网络） |
| 假定不可信 | 互联网、公共 Wi-Fi（「公用」网络）、他人可控的中间设备 |
| 主要风险 | ① 同网段嗅探明文会话与媒体内容（CWE-319）；② 未设密码时的完全公开浏览；③ 弱口令暴力破解 |

## 内置防护（已实现）

- **访问控制**：可选密码（PBKDF2-SHA256 / 100k / 随机盐 / 恒定时间比较）；未设密码时请勿在共享目录存放敏感内容。
- **会话管理**：HttpOnly Cookie、UA 绑定、令牌轮换、逐设备踢出与全部踢出、登录锁定。
- **限流与资源约束**：登录 10 次/分钟、一般请求 300 次/分钟；并发连接上限；首字节与整连接超时；大文件流式输出。
- **暴露面收敛**：设置页可指定**监听网卡**，仅该地址可达；当前网络为「公用」时**拒绝启动**。
- **可审计**：登录成败、锁定、401 / 429、启停均写入应用日志（IP 按 /24 脱敏）。

## 使用前提（必须满足）

1. 仅在**可信的「专用」网络**下开启；「公用」网络下服务会拒绝启动。
2. **必须设置访问密码**；不要在共享库中放入证件、合同等敏感材料。
3. 需要跨网络访问时，**经反向代理终止 TLS**（见下），不要把 8756 端口直接暴露到公网。
4. 路由器不做端口转发；如需外网访问，改用 VPN（如 WireGuard / Tailscale）。

### 反向代理示例（Caddy，自动 HTTPS）

```caddyfile
photos.example.com {
    reverse_proxy 192.168.1.10:8756
}
```

nginx 等价配置需自行签发证书，并在 `location` 中透传 `X-Forwarded-For`（本服务按连接 IP 限流与记录）。

## 已知未做（评估结论）

| 项 | 结论 |
|---|---|
| 内置 TLS（自签证书 + 证书指纹配对） | 未实现。自签证书在移动浏览器上仍有证书警告，且需为握手 / 超时 / Range 流式全链路适配；与 Jellyfin 官方立场一致——**推荐反向代理终止 TLS**，内置 HTTPS 属可选项 |
| 监听 IP 白名单 / RBAC 多用户 | 未实现。单密码 + 网段信任模型，见上表威胁模型 |
| 会话与连接的 IP 绑定 | 有意不做：家庭 DHCP 短租约会误伤正常设备（正常设备被踢下线） |
| 上传 / 写入接口 | 服务为**只读**：仅提供浏览、播放、下载与索引查询 |

## 开启前自检

- [ ] 当前网络为「专用」（Windows 设置 → 网络和 Internet → 属性）
- [ ] 已设置访问密码（≥ 8 位、非纯数字、非弱口令）
- [ ] 监听网卡已按需收敛（不需跨设备访问时无需调整；多网卡机器建议指定）
- [ ] 共享目录不含敏感材料
- [ ] 如需外网访问：已配置反向代理或 VPN，且未做端口转发
